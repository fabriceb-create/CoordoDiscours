# Guide utilisateur CoordoDiscours 1.13

## 1. Ouvrir l’application

À l’ouverture, vérifie :

- le nom de l’assemblée dans l’en-tête ;
- la version affichée ;
- le message **Application prête** ;
- l’absence de bandeau d’erreur réseau.

Sur téléphone, utilise le bouton de menu dans l’en-tête. Le menu se ferme avec son bouton, le fond assombri ou la touche Échap.

## 2. Utiliser l’aide

Le menu **Aide** ouvre le guide complet. La recherche accepte des mots comme `invitation`, `indisponible`, `version`, `déploiement` ou `erreur`.

Le bouton `?` de l’en-tête ouvre le sujet lié au module affiché. Après fermeture, le focus revient au bouton utilisé. La touche `?` ouvre également l’aide, sauf lorsque tu écris dans un champ.

Les sujets visibles dépendent de ton rôle. Une personne en Consultation ne voit pas les procédures réservées à l’administration.

## 3. Lire le tableau de bord

Commence par l’action prioritaire, puis vérifie :

- les prochaines programmations ;
- les invitations à envoyer ou relancer ;
- l’hospitalité à attribuer ;
- les confirmations manquantes ;
- les conflits de créneau.

## 4. Préparer les référentiels

Avant de programmer :

1. crée les assemblées ;
2. crée les orateurs ;
3. indique les discours des orateurs extérieurs ;
4. ajoute leurs disponibilités ;
5. vérifie les titres et statuts des discours.

Un orateur local peut présenter tout discours actif. Un orateur extérieur est limité aux discours déclarés dans sa fiche.

## 5. Programmer un discours

1. Ouvre **Programmation**.
2. Clique sur **Programmer un discours**.
3. Choisis la date, l’heure et le discours.
4. Consulte les orateurs recommandés.
5. Sélectionne l’orateur et son assemblée d’origine si nécessaire.
6. Lis les avertissements.
7. Enregistre après contrôle.

Une erreur bloquante ne peut pas être confirmée. Un avertissement reste enregistrable après confirmation.

## 6. Comprendre les disponibilités

- **Indisponible** : bloque les dates de la période.
- **Disponible seulement** : bloque toutes les dates hors des fenêtres autorisées.
- **Période préférée** : ajoute un bonus au classement.
- **Période à éviter** : ajoute un avertissement et un malus.

Une période désactivée reste dans l’historique mais n’influence plus le moteur.

## 7. Utiliser la planification automatique

1. Choisis la première date, l’heure et une période de 1 à 6 mois.
2. Génère les trois scénarios.
3. Compare Équilibré, Renouvellement des discours et Rotation des orateurs.
4. Décoche les dates non retenues.
5. Enregistre le scénario choisi.

Aucune proposition n’est écrite avant la validation finale. Un brouillon est refusé si les données utilisées ont changé entre-temps.

## 8. Gérer invitations et hospitalité

Pour un orateur extérieur :

- crée ou ouvre l’invitation ;
- complète le destinataire ;
- fais évoluer le statut ;
- attribue l’hospitalité ;
- confirme l’accueil.

Le tableau de bord continue d’afficher l’action tant qu’elle reste incomplète.

## 9. Consulter l’historique

**Historique** répond à la question : « Qui a fait quoi, quand et sur quelle fiche ? »

**Versions** permet de :

- parcourir les états successifs d’une fiche ;
- sélectionner deux versions ;
- comparer leurs valeurs ;
- restaurer un ancien état lorsque ton rôle l’autorise.

Une restauration crée une nouvelle version. Elle n’efface pas les états plus récents.

## 10. Imprimer le planning

Choisis le mois de départ, puis trois ou six mois. Actualise l’aperçu et contrôle les informations avant d’imprimer en A4.

## 11. Réagir à une erreur réseau

### Lecture interrompue

L’application essaie une seconde fois automatiquement. Si l’erreur persiste, le bandeau propose de recharger.

### Enregistrement interrompu

Ne reclique pas immédiatement sur Enregistrer. Recharge d’abord le module et vérifie si la fiche existe ou a été modifiée. Une écriture n’est volontairement jamais répétée automatiquement.

En cas de doute, note :

- le module ;
- l’heure ;
- l’action effectuée ;
- le message affiché.

Transmets ces éléments à l’administrateur.


## Référence de support

Lorsqu’une erreur s’affiche, note la référence `CD-ERR-...` et communique-la à l’administrateur.
